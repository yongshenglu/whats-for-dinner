# 🍚 今天吃什么？

家庭点菜小工具：把会做的菜录进去，每天随机帮你决定吃什么。

**在线使用**：<https://yongshenglu.github.io/whats-for-dinner/>

## 功能

- 🎲 **随机点菜**：一键生成一餐搭配，默认 1 荤 + 1 素 + 1 汤，每类数量可调（0–3）；单道不满意可「换一个」，整套可「重新抽」
- 📖 **菜谱管理**：页面里添加 / 编辑 / 删除，分荤菜、素菜、汤、主食四类，可加备注
- 🔁 **防重复**：默认 7 天内吃过的优先不再出现，天数可改；候选不够时自动放宽，保证能出结果
- 📅 **吃过记录**：点「就吃这个」记入历史，可查看、可删除
- 💾 **数据备份**：数据存在浏览器本地，支持导出 / 导入 JSON，换设备不丢

## 使用说明

打开网页即可用。第一次打开自带 15 道示例家常菜，删掉换成自己会做的就行。

菜谱和记录保存在**当前设备的浏览器**里：换手机 / 换电脑时，在旧设备点「导出备份」，再到新设备「导入备份」即可迁移。

## 本地开发

无需构建，直接用浏览器打开 `index.html` 即可；或者：

```bash
python -m http.server 8000
# 访问 http://localhost:8000
```

## 技术说明

纯 HTML + CSS + JavaScript，零依赖，静态部署在 GitHub Pages。

页面结构（四个功能区各一页，底部标签栏切换）：

| 页面 | 功能 |
|---|---|
| `index.html` | 🎲 随机点菜 |
| `history.html` | 📅 最近吃了什么 |
| `dishes.html` | 📖 我的菜谱（增删改） |
| `backup.html` | 💾 数据备份（导出 / 导入 / 恢复示例） |

`app.js` / `style.css` 为四页共用的逻辑与样式。
